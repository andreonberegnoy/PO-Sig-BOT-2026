⏱ Анализ экспирации

Бот прогоняет ТВОЮ стратегию (CONSENSUS из config) на накопленных свечах с разными экспирациями: 1, 2, 3, 4, 5 баров (1 бар = 1 минута). Показывает какая бы отработала лучше для каждой пары. Используй для подбора оптимального trading.expiry_seconds.

⭐ — лучшая экспирация для пары (≥5 сигналов в окне). В строке «Среднее по всем парам» — средний WR на каждой экспирации. В колонке «Свечей / Сигналов» — сколько свечей просмотрел и сколько виртуальных сделок CONSENSUS совершил на 1000-свечном окне.
