## Как бот торгует (простыми словами)

### Как бот принимает решение войти

Каждую секунду бот сканирует все доступные валютные пары (OTC + основные) и спрашивает у каждой: «Здесь сейчас стоит входить или нет?»

Чтобы ответить **«да, входим»**, должны сойтись:

1. **Выплата ≥ 92%** — иначе пара даже не рассматривается.
2. **Минимум 4 индикатора из 5 согласны** в одну сторону (CONSENSUS 4/5):
   - RSI (перекупленность/перепроданность),
   - QQE (улучшенный RSI),
   - Bollinger Bands (где цена в канале),
   - ATR (волатильность не аномальная),
   - старший таймфрейм EMA20 (общий тренд),
   - + проверка тела свечи.
3. **Пара не в бане**.
4. **Прошло ≥ 3 свечей** после прошлой сделки на этой паре (cooldown).

Если все 4 пункта сошлись → бот ставит **$1** в нужную сторону (call/put), экспирация **2 минуты**.

### Что происходит после сделки

#### Сценарий А: ПЛЮС 🟢

- Прибыль идёт в кассу.
- Сумма входа сбрасывается обратно на **$1**.
- Бот возвращается в режим «свободный поиск» — снова сканирует все пары.
- Текущую пару **не запоминает** — следующий сигнал может быть где угодно.

#### Сценарий Б: МИНУС 🔴

Бот **залипает на этой паре** и идёт в мартингейл — пока не вытащит плюс.

- Минус → следующая ставка × **2.1**:
  - $1 → $2.10 → $4.41 → $9.26 → $19.45 → $40.84 → ...
- **Направление НЕ меняется.** Если первый сигнал был «вверх», все догоны тоже «вверх», независимо от того что показывают индикаторы дальше.
- Пара та же. Жмём до победы.

После плюса (на любом шаге) — мартингейл сбрасывается, $1, свободный поиск.

### Когда бот всё-таки уходит с пары посреди мартингейла

**Только** в одном случае: если **выплата на текущей паре упала ниже 85%** (пока ты в просадке).

- Бот разово переключается на другую подходящую пару (с выплатой ≥ 92%).
- **Шаг мартингейла переносится с собой.** Если был на $9.26 — на новой паре ставит $9.26.
- За один цикл такой переход разрешён **один раз** (`max_pair_switch_per_cycle: 1`).
- Если и на новой паре упала выплата — терпит, не прыгает.

Во всех остальных случаях посреди цикла бот **никуда не уходит**.

### Когда пара уходит в бан

Если на одной паре подряд **больше 3 минусов** (это не один мартингейл-цикл, а именно три цикла подряд закончились просадкой) → пара **банится на 12 часов**.

Если **все пары** в бане → бот уходит в «выходной» на **6 часов**, потом пересматривает.

### Когда бот полностью останавливается

Если суммарная просадка с начала сессии превысила **$1000** → бот ставит на паузу и ждёт от тебя `/resume` в Telegram. Пока не подтвердил — никаких сделок.

### Конкретный пример одной сессии

Старт, баланс $500. Бот сканирует.

**14:02** — на `EUR/USD OTC` 4 из 5 индикаторов говорят «вверх», выплата 93%.
→ Ставка $1, call, экспирация 2 мин.

**14:04** — 🔴 минус. Цена ушла вниз. Баланс $499.
→ Бот **остаётся на EUR/USD**, направление **то же (call)**. Ставка $2.10.

**14:06** — 🔴 минус. Баланс ~$497.
→ Остаётся на EUR/USD, call. Ставка $4.41.

**14:08** — на EUR/USD выплата упала до 84%.
→ Бот ищет другую пару с выплатой ≥ 92%. Находит `GBP/USD OTC`. Шаг переносится: ставка $9.26, **направление прежнее (call)**. Это его единственный разрешённый переход в этом цикле.

**14:10** — 🟢 плюс на GBP/USD. Прибыль ~$8.6. Баланс ~$505.
→ Цикл закрыт. Сброс: $1, свободный поиск. Бот забывает про EUR/USD и GBP/USD, снова сканит все пары.

**14:11** — на `AUD/CAD OTC` сходятся условия, новый сигнал «вниз», выплата 94%.
→ Ставка $1, put.

И так по кругу.

### Все настройки в одном месте

Всё описанное выше регулируется в [config.yaml](config.yaml):

| Настройка | Значение | Что значит |
|---|---|---|
| `filter.min_payout` | 92 | Минимальная выплата для входа в первую сделку цикла (%) |
| `filter.payout_floor` | 85 | Если на текущей паре упало ниже — переключаемся |
| `filter.max_losses_in_row` | 3 | Сколько минус-циклов подряд → бан пары |
| `filter.ban_hours` | 12 | На сколько часов банится пара |
| `filter.min_wr1` | 60 | Минимум **общей проходимости** (за 1000 свечей, %) |
| `filter.min_wr1_recent` | 75 | Минимум **проходимости последних свечей** (за 200, %) |
| `filter.pause_minutes` | 60 | Короткая пауза при провале ТОЛЬКО проходимости последних |
| `filter.temp_pause_hours` | 6 | **Временная пауза** при провале ОБЕИХ проходимостей (per-pair) |
| `trading.base_amount` | 1 | Базовая ставка ($) |
| `trading.expiry_seconds` | 120 | Экспирация сделки (сек) |
| `martingale.coefficient` | 2.1 | Множитель ставки после минуса |
| `martingale.cycle_total_limit` | 7 | Общий лимит сделок в цикле |
| `martingale.pair_limits` | [3,3,2] | Сделок на каждой паре цикла; длина = число пар |
| `martingale.consecutive_losses_switch` | 3 | Минусов подряд для switch на следующую пару |
| `martingale.stop_sum` | 1000 | Стоп-сумма потерь ($) — пауза до /resume |
| `indicator.minConsensus` | 4 | Минимум индикаторов из 5 для входа |

## Как написать свою стратегию

Стратегия — это Python-файл, который **анализирует свечи и возвращает сигналы**. Бот вызывает её на каждом скан-цикле для каждой отслеживаемой пары.

## Минимальный интерфейс

Каждая стратегия должна иметь:

| Имя | Тип | Описание |
|---|---|---|
| `NAME` | str | Человекочитаемое название |
| `DEFAULT_PARAMS` | dict | Словарь параметров со значениями по умолчанию |
| `generate_signals(candles, params)` | func | Возвращает `(signals: list[Signal], diag: dict)` |

## Объект `Signal`

```python
from dataclasses import dataclass

@dataclass
class Signal:
    side: str          # "buy" → action "call" (рост), "sell" → action "put" (падение)
    i: int             # индекс бара сигнала в массиве candles
    votes: dict        # любая dict-структура с диагностикой ({"rsi": 1, "htf": 1, ...})
    total: int         # общее число "голосов"
```

**Бот возьмёт `signals[-1]`**. Если его `i != len(candles) - 1` (т.е. это не последний бар) — сигнал проигнорируется.

## Формат свечей

```python
candles = [
    {"time": 1777070640, "open": 1.197, "high": 1.198, "low": 1.196, "close": 1.197, "volume": 0},
    ...
]
```

- `time` — Unix timestamp **открытия** бара (закрытие = time + period)
- Бары упорядочены по возрастанию `time`
- Последний бар (`candles[-1]`) обычно ещё не закрыт. Стандартная практика — анализировать `candles[:-1]`

## Простой пример (SMA Cross)

```python
from dataclasses import dataclass

NAME = "SMA Cross"
DEFAULT_PARAMS = {"fastPeriod": 9, "slowPeriod": 21}

@dataclass
class Signal:
    side: str
    i: int
    votes: dict
    total: int

def sma(values, period):
    out = [None] * len(values)
    s = 0.0
    for i, v in enumerate(values):
        s += v
        if i >= period: s -= values[i - period]
        if i >= period - 1: out[i] = s / period
    return out

def generate_signals(candles, params):
    p = {**DEFAULT_PARAMS, **(params or {})}
    closes = [c["close"] for c in candles]
    fast = sma(closes, p["fastPeriod"])
    slow = sma(closes, p["slowPeriod"])
    sigs = []
    for i in range(1, len(candles)):
        if fast[i] is None or slow[i] is None: continue
        if fast[i-1] <= slow[i-1] and fast[i] > slow[i]:
            sigs.append(Signal("buy", i, {"cross": 1}, 1))
        elif fast[i-1] >= slow[i-1] and fast[i] < slow[i]:
            sigs.append(Signal("sell", i, {"cross": 1}, 1))
    return sigs, {"found": len(sigs)}
```

## Как загрузить

**Способ 1 — через Mini App (быстро):**
1. Открой Mini App → вкладка **Стратегии**
2. Введи имя файла (буквы/цифры/_, например `my_macd`)
3. Вставь Python-код
4. Кликни **Сохранить и активировать**
5. Бот сразу начнёт использовать твою стратегию

**Способ 2 — через файл (для разработки):**
1. Создай `strategy/user/my_strategy.py`
2. Перезапусти бота — стратегия автоподгрузится
3. Активируй через Mini App или `/api/strategies/my_strategy/activate`

## Параметры

- `DEFAULT_PARAMS` объединяются с глобальными `cfg["indicator"]` из config.yaml
