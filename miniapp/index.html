    📊 Аналитика стратегии

    Будет наполнено в этапе 2 рефакторинга. Согласно плану:

    • Главная таблица: пары × 24h-средние
    • Фильтры периода: 1д / 7д / 14д / 30д / 60д / по дате
    • Сортировка по любому столбцу
    • Клик на пару → раскрытие 24-часовой детализации
    • Плашка «Рабочие часы» (визуальный индикатор активного фильтра)
    • Плашка фильтр по времени (13:00-19:00 — суммарно за период)
    • Колонка «Best exp за последние N сделок» (фильтруемое окно)
    • Кнопка «Применить как фильтр» к стратегии
    • Кнопка «Экспорт данных» (CSV)
    • Цветовая подсветка: 🟢/🟡/🟠/🔴 по WR
